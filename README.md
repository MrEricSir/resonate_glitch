# resonate_glitch
Generative audio in HTML5. Designed to be run on phones.

resonate_glitch takes in various inputs: the camera feed, mic input, and accelerometer motion data on your phone. Running these parameters through an algorithm, it produces synthesized electronic "music" with a glitchy camera view.

The aim of the project is to create a synthetic synchronicity. Does the music have any meaning? Are you able to affect it in any way? It's up to the user to experiment and find out.

Note: There is no backend server, everything runs in your web browser. So while the webapp can't be used for spying, it may cause your phone to overheat.

[Try it yourself!](https://mrericsir.github.io/resonate_glitch/)
